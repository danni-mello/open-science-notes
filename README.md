# open-science-notes



Anotações e exercícios práticos de estudo do currículo NASA TOPS Open Science 101.



## Estrutura

- `00-material-original/`: currículo original da NASA, sem alterações (Module\_1 a Module\_5)

- `01` a `05`: anotações e práticas de cada módulo

- `06-osdmp/`: rascunho de Open Science and Data Management Plan
